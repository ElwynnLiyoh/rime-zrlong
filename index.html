自然龙 是一种在传统双拼基础上进行创新的输入法，它使韵母带调，采用四码定长的方式进行输入。
相比传统方案，它更确定、更高效，且富有节奏感。
免责声明：本仓库为自用分享，可能存在诸多不足和错误。如果您选择使用此仓库，请自行承担可能产生的风险和责任。

韵调统一

将韵母带上声调并统一在一个键上。解决了传统双拼重码多的问题，也避免了传统带调方案码长过长的问题。

静态码表

使用静态码表，确定性 100%，所有字词尽在掌握。可随意盲打，安全感拉满。告别动态调频带来的忽前忽后。

四码定长

单字和词组最大码长为 4。打 2 字词声韵声韵，节奏感强，输入体验舒适。

双拼加形

结合双拼高效率与形码高准确性。采用自然码辅助码：首码义部优先，次码取大，直观自然。

手感优化

韵母分布利用程序算法 + 人工设计，重码率和手感皆超过传统音形、形码输入法。

字词库大

目前已包含 4.5 万 + 单字和 16 万 + 词组，满足各种输入场景。

安装

注意：首先确保已经装了 Rime (中州韵)，若已有配置文件请先备份。

使用 Git 安装 (推荐)

如果您已经安装了 Git，可以直接在终端执行以下命令：

git clone --depth=1 https://github.com/Elflare/rime-zrlong.git "您的 Rime 用户目录"

手动安装

  1. 下载 Release 文件：点击 Releases，找到最新的压缩包下载。
  2. 解压：将下载的 ZIP 文件解压。
  3. 复制文件：将里面的所有文件（包含文件夹）解压到您的 Rime 用户目录。

快捷工具

  • 时间：输入 sj → 当前时间
  • 日期：输入 orq → 当前日期
  • 日期时间：输入 ors → 日期+时间
  • 数字大写：S + 数字（如 S123）→ 一百二十三
  • Emoji：Ctrl + e 切换 Emoji 滤镜
  • 英文输入：首字母大写 + 回车（Zrlong ⏎ → zrlong）；首字母大写 + 空格（Zrlong ␣ → Zrlong）
  • 简码提示：候选框会显示字或词的简码提示

飞键

仅将声母 y 飞到了 e 键上（因为 e 的英文发音类似 y），韵母不受影响。飞键权重较低，不影响正常编码。
